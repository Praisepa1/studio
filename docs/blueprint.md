# **App Name**: JobJet

## Core Features:

- Application Tracker: Dashboard to track applications and their status.
- Smart Search: AI-powered search filter suggestions based on job description analysis using an LLM tool.
- Profile Optimizer: AI-driven profile optimization suggestions based on job requirements for both Upwork and LinkedIn. This functionality will use a LLM to optimize the profile.
- Automated Application: Direct application submission for Upwork and LinkedIn jobs.
- User Management: User account management (login, profile settings).
- Resume Generation: AI and manual resume generation.
- Cover Letter Generation: AI and manually generated application letters/pitches.

## Style Guidelines:

- Light gray (#F0F2F5) background to ensure comfortable readability and a clean interface.
- Soft blue (#64B5F6) primary color for a professional and trustworthy feel.
- Muted purple (#9575CD) accent color for highlighting key actions.
- Clean, sans-serif font for clear readability on all devices.
- A clean and intuitive grid-based layout to organize the job search and application process efficiently.
- Simple and recognizable icons to represent job categories, application status, and profile sections.
- Subtle transitions and animations to provide feedback during interactions.
